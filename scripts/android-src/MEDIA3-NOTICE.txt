Uses the Android platform MediaCodec implementations. No FFmpeg/libmpv,
software codec extension or Cronet/GMS network stack is included by this
player. Actual container/codec/profile capability depends on the device.

This is a development feasibility candidate, not a formal distribution or
codec-patent clearance. Existing declared application dependencies are retained.
Resolved transitive additions/upgrades and their dependency notices are reviewed
with the candidate's dependency review before any formal distribution.
