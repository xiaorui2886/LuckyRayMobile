# 手机素材详情：接入与验收

基线：44f35d4b82a7b5e5a427da3e0fe4a8d3c033651f。仅源码，未生成 APK、未发布。

## 本轮改动

- 本机和电脑素材详情均可单指左右划到当前列表的上一项、下一项。顺序取打开时当前过滤/排序后的已加载列表快照；到边界停止，不循环，也不跨本机/电脑或另一台电脑。它不是跨全部分页的浏览器，尚未加载的页不暗中请求。
- 详情替换沿用导航控制器，不累积每次划动的历史。返回仍回原列表。两指缩放、放大后平移、控件、全屏播放、弹窗不抢切换手势。短小、斜向和长时间拖动不触发切换；鼠标拖动和文字选择不触发。切换后由文档级拦截阻止拖动尾随点击落到新素材，键盘激活不受影响。
- 视频从准备阶段开始保留同一深色舞台，未有解码画面时不暴露浏览器的破图图标。元数据就绪即提供播放按钮，不以 canplay 为播放前提，避免 metadata 预载死锁。
- 控件提供播放/暂停、进度、已播/总时长、静音、0.5–2 倍速和全屏；播放时安静收起，点画面再显示。隐藏控件退出键盘 Tab 顺序。图标有无障碍名称。
- 优先浏览器全屏；不支持时在当前详情中展开沉浸舞台。系统返回先退出该舞台，不额外跳播放器页面。
- 未改变原有本机完整性验证、电脑授权/来源围栏、Range 播放、播放租约释放和不支持编码时的本机播放器兜底。不存在新增第三方播放器或网络服务。

## 已验证

- TypeScript 检查通过。
- tests/mobileAssetViewerOvernight.test.ts、mobileMediaDetailR6.test.ts、materialSelectionR5.contract.test.ts 合计 26 项通过，覆盖排序边界、来源隔离、短划判定、连续替换历史、时间与进度边界、加载样式契约、缓存/远程租约、迟到授权释放、选择模式与操作保留。
- validation/asset-player-dom.mjs 使用 React 和 jsdom、模拟媒体 API：元数据先到时可点击播放；解码后显示；自动隐藏不会被 timeupdate 无限重置；隐藏控件不可 Tab；播放/静音/倍速/就地全屏/返回/卸载释放均通过；另验证旧 WebView 不支持 focus-visible 选择器时不抛错，以及原页面移除后尾随点击仍被拦截。
- DOM 测试所需可选测试工具为 jsdom、esbuild，可正常安装后直接运行；已有环境可用 JSDOM_MODULE 和 ESBUILD_MODULE 指向其入口。该测试不访问电脑素材、不调用生成服务。

- validation/asset-swipe-dom.mjs 执行实际 StillAsset/ZoomStage 函数体：首尾划不导航后再次触摸不误判双指，真正的双指缩放仍可用；重放修复前的 capture 阻断时测试确实失败。此验证不模拟 Android 原生 pointer capture。

## 必须在测试手机验证，当前 NOTRUN

1. 在本机/电脑分别设置过滤、排序，连续向两侧切换；首尾不循环，返回列表位置保持；两指缩放不误切。
2. 电脑连接切换、授权撤销、视频缓冲中连续切换，旧画面不串入新素材，离开后停止声音和旧传输。
3. 实际手机编码、长视频 Range seek、静音/倍速、全屏/旋转/系统返回、系统状态栏与安全区。
4. 很窄的屏幕、深浅主题、减少动态、辅助功能阅读器以及横竖屏控件无遮挡。
5. 不支持直接播放的素材仍可用既有本机播放器兜底；不许把这条 DOM 验证当作真实编码兼容证据。

本轮没有真实 Android 画面、帧率或媒体解码实测证据，请由 Codex 接入后执行并回执。
