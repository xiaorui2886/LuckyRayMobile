# ADR-0005: Additive current-Vault unique creation and editing advice

Revision `2026-09-30.1` / Services major1 minor2 adds exactly seven operations approved by the Knowledge and Mobile deputies: createUnique, editing, editingOpen, editingSet, directories, relations, materialReferences. Desktop baseline is `8a4ae9dbb815abf28bc39d78c9ef136c222fd2df`; domain candidate is `c2789536cd51764a0a3a9c6e63f17c3ad0f4372e`. The complete directory is sealed as one byte bundle; the prior Services revision is not silently rewritten. This publication is a shared engineering candidate, not production UI/LAN/phone-install acceptance.

Content V1 `2026-09-21.1` remains byte-identical. New unique-create DTOs reference/import it, never widen it. Creation uses the existing Knowledge mutation lock, no-replace publication, durable Content identity/receipt journal, and server-selected title / title（副本） / title（副本 2）. Exact retry payload and originally prepared route stay immutable, including omitted/null/empty expectedRevision. Changed payload under the same opId is409; ambiguous commit is preserved rather than retried via another route.

Presence is ephemeral advice, not a content lock or sync authority. Only POST obtains an inert15s128-bit server token. Only a higher-generation PUT on that still-live device/note/physical-target token changes advice; PUT never allocates, expired/released tokens return410, and equal/older generations do not renew. Release and expiry reclaim capacity (512 unexpired reservations/live leases); no lifetime tombstones, durable advice state or new outbox. Mobile lazily opens only after a durable local edit and a current visible owner, retires late POST/old410 responses, and never lets presence failure block saves. Actual desktop dirty draft and revision protections remain authoritative.

Knowledge/Catalog remain the sole production index/binding authorities. Read-only relative directories are live, and relation cursors are snapshot/scoped, not durable Content cursors. Catalog read AND Vault read is required for reverse material references. No new grants, inactive-Vault activation, arbitrary filesystem/raw access, CRDT, inferred relations or external fetching.

The desktop committed listener emits only a scoped wake-up. A cheap in-memory incarnation/sequence checkpoint closes missed-emission gaps without periodic full index scans; it is main-WebView-only, and source ownership/dirty-generation checks remain in the existing reader. This checkpoint is a desktop implementation detail, not a remote canonical wire route.

Synthetic fixtures model the approved wire decisions and controlled clock/capacity/cursor cases; production native/TLS and ordinary UI/LAN evidence are recorded separately. Other service operations, foundation capabilities/events and legacy Content requests remain compatible. Higher major/unknown operations fail closed.
